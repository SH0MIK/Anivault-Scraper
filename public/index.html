// AniVault API — Documentation

Stream Anything.
From Anywhere.

A unified REST API to fetch anime stream URLs and embed links across multiple sources, addressed by MAL or AniList ID. Railway-ready, zero config.

Online 3 Streaming Sources MAL Scraper TMDB · Kitsu · AniList Sub · Dub · Raw

URL Structure
Path-based is recommended. Query-based is also supported for backward compat.
Path-based (recommended) 
# /api/watch/{source}/{id}/{ep}/{type}?server=Name
# id = AniList ID  OR  mal-{malId}

GET /api/watch/anikoto/20/1/sub
GET /api/watch/desidub/mal-16498/1/dub?server=VMoly
GET /api/watch/animeheaven/{heavenId}/3/sub
Query-based (compat) 
GET /api/watch?source=desidub&malId=16498&ep=1&type=dub
GET /api/watch?source=anikoto&anilistId=20&ep=1&type=sub
GET /api/watch?source=animeheaven&heavenId=ukr6y&ep=5&type=sub

GET /api/watch/{source}/{id}/{ep}/{type} Embed URL + m3u8 + subtitles ▼
ParamTypeWhereDescription
sourcestringpathanimeheaven · anikoto
idstringpathAniList ID or "mal-{malId}"
epnumberpathEpisode number
typestringpathsub · dub · raw
serverstringqueryPreferred server name (optional, e.g. "Megacloud")
Example Response 
{
  "anilistId": 20, "malId": 20, "title": "Naruto",
  "episode": 1, "type": "sub", "source": "anikoto",
  "server": "Megacloud",
  "availableServers": ["Megacloud", "Vidstreaming"],
  "embedUrl": "https://megacloud.blog/embed-2/e-1/AbCdEf",
  "m3u8": "https://cdn.megacloud.blog/hls/abc/master.m3u8",
  "subtitles": [{ "lang": "English", "url": "https://.../en.vtt", "default": true }],
  "intro": { "start": 0, "end": 90 },
  "outro": { "start": 1350, "end": 1440 },
  "note": null    // non-null = m3u8 failed, use embedUrl instead
}

GET /api/{anilist|tmdb|kitsu}/anime Poster + cover art (+ logo on TMDB) — same shape across all 3 ▼
ParamTypeRequiredDescription
malIdnumberone ofMAL anime ID
titlestringone ofDirect title search, skips MAL lookup (TMDB/Kitsu only)
liststringoptional1 to skip cache (fresh lookup)
Example: /api/tmdb/anime?malId=16498 
{ "data": { "poster": "https://image.tmdb.org/t/p/original/...", "cover": "https://image.tmdb.org/t/p/original/...", "logo": "https://image.tmdb.org/t/p/original/..." }, "log": ["..."] }
Example: /api/kitsu/anime?malId=16498 
{ "data": { "poster": "https://media.kitsu.app/anime/poster_images/.../original.jpg", "cover": "https://media.kitsu.app/anime/cover_images/.../original.jpg" }, "log": ["..."] }
GET /api/{tmdb|kitsu}/episode-thumb Single episode still/thumbnail ▼
ParamTypeRequiredDescription
epnumberrequiredEpisode number
malIdnumberone ofMAL anime ID
titlestringone ofDirect title search
Example Response 
{ "data": { "thumbnail": "https://image.tmdb.org/t/p/original/still.jpg" }, "log": ["..."] }

GET /api/episode MAL episode metadata + thumbnail (single episode, or the whole show) ▼
ParamTypeRequiredDescription
malIdnumberrequiredMAL anime ID
epnumberoptionalOmit for the whole show's episode list
concurrencynumberoptionalWhole-show mode only. Default 5, max 10
liststringoptional1 to skip thumbnail cache
Example: single episode (?ep=1) 
{
  "data": {
    "malId": 16498, "episode": 1, "title": "To You, 2000 Years in the Future",
    "aired": "Apr 7, 2013", "filler": false, "recap": false,
    "thumbnail": "https://media.kitsu.app/...", "thumbnailSource": "kitsu"
  },
  "log": ["..."]
}
Example: whole show (no ?ep=) 
{
  "malId": 16498, "title": "Attack on Titan", "count": 25,
  "episodes": [{ "episode": 1, "title": "...", "thumbnail": "...", "thumbnailSource": "tmdb" }]
}
